# SalesReport — автоматизация Excel-отчётов

**SalesReport** — Python-программа для автоматизации обработки данных из Excel-файлов и формирования отчётов.

Проект демонстрирует использование Python для решения практических задач по обработке табличных данных.

## Возможности

- Чтение Excel-файлов формата `.xlsx` из папки `input`.
- Обработка и объединение данных из входных файлов.
- Формирование итогового отчёта в папке `output`.
- Проверка наличия входных Excel-файлов и вывод понятного сообщения, если папка `input` пуста.
- Запуск в виде исполняемого файла `.exe`.

## Технологии

- Python
- pandas
- openpyxl
- PyInstaller
- Git и GitHub

## Как использовать

1. Запустите программу `SalesReport.exe`.
2. Поместите исходные Excel-файлы в папку `input`, расположенную рядом с программой.
3. Запустите программу.
4. Найдите сформированный отчёт в папке `output`.

Если в папке `input` нет Excel-файлов, программа сообщит об этом и предложит нажать Enter для выхода.

## Запуск из исходного кода

Для запуска проекта из Python установите зависимости:

```bash
pip install -r requirements.txt
```

Затем выполните файл `src/SalesReport.py`.

## Сборка EXE

Для создания исполняемого файла используется PyInstaller:

```bash
python -m PyInstaller --noconfirm --clean --onedir --console --name SalesReport src/SalesReport.py
```

Готовая сборка появится в папке `dist/SalesReport`.
