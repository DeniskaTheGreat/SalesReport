# SalesReport — автоматизация Excel-отчётов

**SalesReport** — программа на Python для автоматической обработки нескольких Excel-файлов, объединения данных и формирования аналитического отчёта.

Программа помогает сократить ручную работу с таблицами: объединяет заказы, удаляет дубликаты, рассчитывает показатели и формирует отчёты по городам и крупным заказам.

## Возможности

- Чтение нескольких Excel-файлов формата `.xlsx` из папки `input`.
- Объединение данных из файлов в единую таблицу.
- Удаление полных дубликатов записей.
- Проверка наличия обязательных столбцов и пропущенных значений в суммах заказов.
- Расчёт количества заказов, общей суммы, среднего чека и самого крупного заказа.
- Формирование отчёта по городам: общая сумма, количество заказов и средний чек.
- Фильтрация крупных заказов по заданному порогу.
- Сортировка заказов по сумме.
- Формирование Excel-книги с пятью листами и автоматическим форматированием таблиц.
- Запуск в виде исполняемого файла `.exe`.

## Формат входных данных

Программа обрабатывает файлы `.xlsx`, расположенные непосредственно в папке `input`.

Каждый файл должен содержать следующие столбцы:

| Столбец | Назначение |
|---|---|
| `name` | Имя клиента |
| `amount` | Сумма заказа |
| `city` | Город |

Названия столбцов могут содержать заглавные буквы: программа приводит их к нижнему регистру.

Если обязательные столбцы отсутствуют или в столбце `amount` есть пропущенные значения, программа сообщает об ошибке и прекращает обработку.

## Результат работы

Программа создаёт файл `output/sales_report.xlsx` с пятью листами:

- **Заказы** — объединённые данные без полных дубликатов.
- **Крупные заказы** — заказы с суммой выше заданного порога.
- **Заказы по сумме** — все заказы, отсортированные по убыванию суммы.
- **Общий отчёт** — основные показатели по заказам.
- **Отчёт по городам** — агрегированные показатели для каждого города.

При запуске программа запрашивает минимальную сумму крупного заказа.

## Как использовать

1. Поместите исходные Excel-файлы в папку `input`.
2. Запустите `SalesReport.exe`. При стандартной сборке через PyInstaller файл находится в `dist/SalesReport/SalesReport.exe`.
3. Введите минимальную сумму крупного заказа.
4. После завершения обработки откройте `output/sales_report.xlsx`.

Если в папке `input` нет Excel-файлов, программа сообщит об этом. Если входные данные не соответствуют требованиям, программа выведет сообщение об ошибке.

## Запуск из исходного кода

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите программу из корневой папки проекта:

```bash
python src/SalesReport.py
```

Для выполнения команд Python и `pip` должны быть доступны из терминала.

## Сборка EXE

Для создания исполняемого файла используется PyInstaller:

```bash
python -m PyInstaller --noconfirm --clean --onedir --console --name SalesReport src/SalesReport.py
```

Готовая сборка появится в папке `dist/SalesReport`.
